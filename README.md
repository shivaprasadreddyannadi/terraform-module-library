# Terraform Module Library

![Terraform](https://img.shields.io/badge/Terraform-1.15+-844FBA?logo=terraform&logoColor=white)

Reusable Terraform modules for building enterprise Azure infrastructure.

## Repository Purpose

This repository contains reusable Terraform modules following Infrastructure as Code best practices.

The modules are designed to be consumed by multiple projects and environments.

## Available Modules

- Resource Group
- Virtual Network
- Storage Account
- Key Vault
- Managed Identity
- Log Analytics
- Private Endpoint
- Application Gateway
- AKS
